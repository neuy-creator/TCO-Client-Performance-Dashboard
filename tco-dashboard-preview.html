✅ How to Keep This Dashboard Updated

  • Organic data → update Brand Data (Industry) - Organic sheet in TCO Data Hub monthly after each reporting cycle.
  • F&B paid → update Brand Data (F&B) - Paid media sheet monthly. Add new months at the bottom.
  • RE paid → update Brand Data (Real Estate) - Paid sheet monthly for both Leadgen and Message sections.
  • Other paid → update Brand Data (E-commerce) - Paid sheet for purchase/message brands monthly.
  • New brands or CPM benchmarks → add to Brand Summary - Paid in Paid Media Data Hub at end of each 6-month period.
  • Use the TCO - Paid Media Monthly Template.xlsx (already built) as the ideal structure going forward.
